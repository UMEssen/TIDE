# TIDE
![alt text](images/tide-git-banner.png "TIDE Banner")
## Objective
The goal of this FHIR package is to support interoperable representation of high-frequency medical time-series data
## Results
Six primary FHIR artifacts were developed:
1. **TIDE Observation**
2. **TIDE Data Endpoint**
3. **RawDataEndpoint Extension**
4. **PreviewEndpoint Extension**
5. **CodeSystem**
6. **ValueSet**
